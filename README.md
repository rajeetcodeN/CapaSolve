# schedulersaas-

Production Scheduling & Capacity Planning SaaS Platform.

## Overview
SchedulerSaaS is a full-featured shop floor scheduling and capacity management system built with TanStack Start, React 19, Tailwind CSS, and Supabase.

## Getting Started

### Prerequisites
- Node.js 18+ or Bun
- npm / pnpm / bun

### Installation & Running
```bash
cd flow-sync-saas
npm install
npm run dev
```

### Build
```bash
cd flow-sync-saas
npm run build
```
